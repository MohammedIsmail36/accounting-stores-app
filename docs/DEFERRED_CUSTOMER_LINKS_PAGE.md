# صفحة روابط العملاء — مهمة مؤجلة

آخر تحديث: 2026-09-07
الحالة: مؤجلة حتى اكتمال تنظيف المستودع واستقرار مسار النشر والإنتاج

## القرار الحالي

- أُزيلت `public/links.html` من cleanroom لأنها ليست جزءاً من تطبيق المحاسبة، وكانت ملفاً غير صالح يجمع صفحتين ويحتوي روابط وهمية.
- أزيلت نسختها من `dist` المحلي حتى لا تظهر في أي معاينة للنسخة النظيفة.
- لم تُحذف النسخة المنشورة حالياً من Farida أو Alibea أو Staging، ولم يتغير Nginx.
- النسخة الأصلية قابلة للاسترجاع من تاريخ المستودع القديم إذا لزم الرجوع إلى تصميم أو رابط منها.

## الهدف اللاحق

إنشاء صفحة خارجية سريعة لعملاء المتجر تعرض وسائل التواصل الصحيحة دون ربطها بتطبيق المحاسبة أو قاعدة بياناته.

## ضوابط الأمان

1. نطاق فرعي مستقل عن نطاق جلسة تطبيق المحاسبة، مع إبقاء الرابط القديم كتحويل بعد الاعتماد.
2. ملفات HTML وCSS ثابتة فقط، ومن دون Supabase أو `/api` أو مفاتيح أو cookies.
3. لا JavaScript إلا لسبب ضروري ومراجع؛ التصميم الأساسي لا يحتاجه.
4. خطوط وأصول محلية، ومن دون متتبعات أو مكتبات خارجية.
5. سياسة CSP صارمة مع `frame-ancestors 'none'` وترويسات `nosniff` وReferrer وPermissions Policy.
6. روابط حقيقية فقط، مع `rel="noopener noreferrer"` للروابط الخارجية.
7. تصميم عربي Mobile-first، واضح وقابل للوصول، وهوية محددة لـFarida أو Alibea دون خلط.
8. اختبار مستقل ثم نشر لا يغير واجهة المحاسبة أو API أو قواعد البيانات.

## البيانات المطلوبة عند استئناف المهمة

- تحديد هل الصفحة لـFarida فقط أم لكل شركة صفحة مستقلة.
- الشعار والاسم والوصف المعتمد.
- أرقام وروابط WhatsApp وFacebook وInstagram وTelegram وTikTok والموقع الجغرافي الصحيحة.
- اسم النطاق الفرعي المختار.

هذه المهمة لا تعيق إكمال تنظيف المشروع أو إنشاء المستودع الجديد.
