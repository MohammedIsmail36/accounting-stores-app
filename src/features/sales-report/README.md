# Sales report feature

هذا المجلد هو النطاق الوحيد لكود تقرير المبيعات.

- `components/`: واجهة التقرير ومكوّناته.
- `domain/`: القواعد والحسابات الخاصة بالتقرير، مع اختبار كل وحدة بجوارها.
- `hooks/`: حالة التقرير وتفضيلاته، ثم استعلامات البيانات عند نقلها تدريجياً من المكوّن الكبير.

يبقى `src/pages/reports/SalesReportPage.tsx` نقطة دخول المسار فقط. أما الأدوات العامة المشتركة بين أكثر من ميزة فمكانها `src/lib/`.

ملفات `*.test.ts` لا تدخل في بناء الإنتاج؛ يلتقطها Vitest فقط وفق `vitest.config.ts`.
