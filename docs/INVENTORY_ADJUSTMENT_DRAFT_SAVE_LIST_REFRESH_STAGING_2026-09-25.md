# ظهور المسودة فور الرجوع إلى القائمة — Staging

بعد نجاح قبول حذف المسودة من الواجهة، أبلغ المستخدم أن المسودة الجديدة `#25` لم تظهر في القائمة عند الرجوع من شريط التنقل حتى تحديث الصفحة. أكد استعلام Staging للقراءة فقط وجود `#25` بحالة `draft` وبند واحد، وبقاء `#21` ببندين، وعدم وجود بنود يتيمة. لذلك لم تكن المشكلة في حفظ المستند، بل في إعادة استخدام قائمة React Query القديمة ذات مهلة صلاحية دقيقة واحدة.

بعد نجاح `save_inventory_adjustment_draft` تمحى نتيجة قائمة `inventory-adjustments` المخزنة محليًا قبل الانتقال إلى تفاصيل المسودة. عند الرجوع إلى القائمة تُجلب البيانات من الخادم. لم تتغير قاعدة البيانات أو دالة الحفظ، ولا تُمحى القائمة إذا فشل الحفظ. تُستخدم وحدة الكاش المشتركة نفسها التي تعالج اختفاء المسودة بعد الحذف.
