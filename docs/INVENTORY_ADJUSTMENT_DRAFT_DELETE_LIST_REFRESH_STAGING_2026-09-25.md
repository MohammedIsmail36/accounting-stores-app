# اختفاء المسودة فور حذفها من القائمة — Staging

أثبت اختبار المستخدم حذف المسودة `#23`، لكن القائمة أظهرتها حتى تحديث الصفحة. أكد استعلام قراءة فقط عدم وجود `#23` في Staging، وعدم وجود بنود تسوية يتيمة، وبقاء `#21` مسودة ببندين. كان السبب أن صفحة تفاصيل التسوية انتقلت إلى القائمة دون تحديث مفتاح React Query `inventory-adjustments`، بينما إعداد التطبيق يحتفظ بنتيجة القائمة دقيقة واحدة.

أضيفت دالة مشتركة تزيل السجل المحذوف فورًا من كاش القائمة وتطلب إعادة جلب القائمة من الخادم. تستخدمها صفحة التفاصيل والقائمة نفسها بعد نجاح الحذف فقط. اجتازت اختبارات الكاش والربط والأنواع، دون أي Migration جديدة.
