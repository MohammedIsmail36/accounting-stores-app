# نظام المحاسبة وإدارة المخزون

تطبيق React + Vite + TypeScript + Tailwind يستخدم Supabase كخلفية.

الاسم التقني للمشروع: `store-accounting-app`.

## التشغيل محلياً

```bash
npm ci
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```

راجع:

- `docs/LOCAL_SETUP_GUIDE.md` للإعداد المحلي.
- `docs/DEPLOYMENT_WORKFLOW.md` للنشر؛ وهو دليل النشر التشغيلي الوحيد.
- `docs/SCRIPT_INVENTORY.md` لمعرفة وظيفة سكربتات المشروع وحدود أمانها.
- `docs/SQL_INVENTORY.md` لمعرفة المصدر الرسمي لملفات قاعدة البيانات وما هو مؤرشف.
- `docs/PROJECT_FILE_INVENTORY.md` لمعرفة وظيفة ملفات الجذر والأصول العامة.
- `docs/DEFERRED_CUSTOMER_LINKS_PAGE.md` لخطة إعادة صفحة روابط العملاء بعد استقرار الإنتاج.
- `docs/PLATFORM_REFERENCE_AUDIT.md` لنتيجة فحص الانفصال عن المنصة السابقة وقائمة المراجع التاريخية المسموحة.
- `docs/L6_REPOSITORY_BOOTSTRAP_REPORT.md` لحالة إنشاء تاريخ Git النظيف والمستودع الجديد.
